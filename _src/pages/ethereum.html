A state machine anyone can program

Bitcoin replicates one kind of state: who owns which coins. Ethereum replicates a general-purpose computer. Anyone can upload a program, a smart contract, and every node runs it in exactly the same way, so its results are as trustworthy as the chain itself.

Vitalik Buterin described it in a 2013 white paper. Gavin Wood wrote its formal specification, the Yellow Paper, and the network went live on 30 July 2015. Its native currency is ether (ETH, symbol Ξ).

Accounts and addresses

Externally owned accounts
Controlled by a private key held by a person or a program. Only these can start a transaction.
Contract accounts
Controlled by their code. They run when a transaction or another contract calls them, and can hold ether and data.
Addresses
20 bytes, written as 40 hexadecimal characters starting with 0x.

The world state is the balance, code and storage of every account. Each block commits to it with a single root hash, using a Merkle Patricia trie: the idea from block #0.

The Ethereum Virtual Machine

Contracts run on the Ethereum Virtual Machine (EVM), a simple stack machine that every node implements identically. The EVM is deterministic: no clocks, no randomness and no network calls. That is exactly what state machine replication demands, and it is why contracts need oracles to learn about the outside world.

The EVM can express any computation (it is Turing-complete), so a contract could loop forever. Gas stops that: every instruction has a price, and a transaction can only run as long as the gas it paid for. Most contracts are written in Solidity or Vyper and compiled to EVM bytecode. Early languages such as Serpent, LLL and Mutan are no longer used.

Gas and fees

Since the London upgrade in August 2021 (EIP-1559), a transaction's fee is:

fee = gas used × (base fee + priority fee)

  • Gas used depends on the work done. A plain ETH transfer always uses 21,000 gas.
  • Base fee is set by the protocol and rises or falls with demand for block space. It is burned, not paid to anyone.
  • Priority fee is a tip to the validator who includes the transaction.

Fees are quoted in gwei. 1 ether = 109 gwei = 1018 wei, wei being the smallest unit.

Try it: work out a fee

21,000 × (10 + 2) gwei = 252,000 gwei = 0.000252 ETH. Burned: 210,000 gwei; to the validator: 42,000 gwei.

The priority fee is capped so that base fee + priority fee never exceeds the maximum fee the sender set. This is the worked example from ethereum.org's gas page. No prices are fetched: this site never tracks markets.

Tokens

ERC-20
The standard interface for fungible tokens, where every unit is the same, like currency or points (EIP-20). A token contract exposes totalSupply, balanceOf, transfer, approve, allowance and transferFrom.
ERC-721
The standard for non-fungible tokens (NFTs), where each token has its own ID and owner, such as a ticket, a certificate or an artwork record (EIP-721).

Because tokens share an interface, any wallet or exchange contract can handle any token. Applications built from these pieces include decentralised exchanges, lending markets, stablecoins and DAOs, organisations whose rules are enforced by contracts.

From proof of work to proof of stake

Until 2022, Ethereum agreed on blocks by proof of work, like Bitcoin. On 15 September 2022, in an upgrade called The Merge, it switched to proof of stake without stopping the chain.

  • Validators lock up at least 32 ETH as stake, propose blocks and vote on them.
  • Validators vote on a checkpoint at the start of each epoch (32 slots of 12 seconds). Once validators with two-thirds of the stake vote for a checkpoint and the next one, it becomes final, along with every block before it, usually in about 13 minutes. Two-thirds is the Byzantine threshold from block #2.
  • Validators who sign conflicting votes are slashed: they lose part of their stake and are removed.
  • Ethereum's electricity use fell by more than 99.98%, according to the Crypto Carbon Ratings Institute (CCRI) estimate cited on ethereum.org.

Many independent teams write Ethereum node software in different languages, including Go, Rust, C#, Java, Nim and TypeScript. That way a bug in one client cannot take down the whole network.
