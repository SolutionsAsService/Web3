Web3 from first principles

Five blocks, hash to oracle.

Web3 is built from a few old ideas in computer science. This site walks through them in order, one block at a time: fingerprints, replicas, traitors, a world computer, and the oracles that let it see out.

Each block's hash is SHA-256 of the previous hash and its source files. Press verify to recompute all five here, using your browser's own crypto. The empty circles fill in as each block checks out.

Why this order

  1. #0IntegrityA hash proves data hasn't changed. A Merkle tree does it for a whole data set at once.
  2. #1ReplicationCopies of a deterministic program stay in step if they agree on the order of inputs.
  3. #2DistrustAgreeing on that order when some copies lie takes more than three honest nodes for every traitor.
  4. #3The platformPut all three together, open it to anyone, and you have Ethereum.
  5. #4The outside worldA deterministic chain can't see out, so oracle networks bring data in using the same tricks.

How this site is a chain

Each block's hash is SHA-256(previous hash ‖ source files). The source files are the original research notes this site was written from, kept byte for byte. Change one comma in block #0's notes and all five hashes change. Each block's little pixel badge is an identicon drawn from its own hash, so a changed block also looks different. The About page shows how to check it yourself from the command line.
