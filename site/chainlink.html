The oracle problem

Smart contracts are deterministic: every node must get the same result, so a contract cannot call a web API or read a sensor. Different nodes might see different answers, and the chain would split. So how does a crop-insurance contract learn the rainfall, or a lending contract the price of an asset?

Something must post the data on-chain as a transaction. That something is an oracle. If one party runs the oracle, the contract is only as trustworthy as that party, which undoes the point of a blockchain. This is the oracle problem.

A decentralised oracle network

Chainlink answers the oracle problem with the same idea as the chain itself: don't trust one reporter, trust a quorum. It was described in a 2017 white paper by Steve Ellis, Ari Juels and Sergey Nazarov, and its main network launched in 2019.

  1. Many independent node operators each fetch the value from several data sources.
  2. Each signs and submits its report.
  3. The reports are aggregated, typically by taking the median, and the result is written on-chain for contracts to read.

A median is robust in a Byzantine sense. As long as fewer than half the reports are faulty, the median lies between two honest values, however wild the faulty ones are.

Try it: one node lies

Seven nodes report a temperature in °C. Drag node 7 as far as you like, and watch the mean move while the median barely changes.

Median 21.4 °C · mean 21.4 °C

Since 2021, Chainlink's design has computed reports off-chain and posted one signed result per round (Off-Chain Reporting), which costs far less gas than one transaction per node. The Chainlink 2.0 white paper (2021) extends the network toward general off-chain computation.

What oracle networks provide

Data feeds
Regularly updated on-chain values, mostly asset prices used by lending and trading contracts. See Chainlink Data Feeds.
Verifiable randomness
A contract can't generate a fair random number by itself. A verifiable random function (VRF) gives a random value with a cryptographic proof that the oracle could not choose or predict it.
Privacy-preserving data
DECO, developed at Cornell and acquired by Chainlink in 2020, lets a user prove a fact about data from a website, such as "my balance is over X", without revealing the data. Town Crier, acquired in 2018, used trusted hardware to fetch web data.

The LINK token

Node operators are paid in LINK, a token on Ethereum with a fixed supply of one billion. LINK follows ERC-677, an extension of ERC-20 that can transfer tokens and call the receiving contract in one step. The network also runs on many other blockchains besides Ethereum.

This site explains how these systems work. It is not advice to buy, sell or hold any token.

Full circle

An oracle network uses the ideas of all four earlier blocks:

  • Reports are signed, and results are committed by hash (block #0).
  • Nodes must agree on one value per round (block #1).
  • Some nodes may lie, so the threshold and the median carry the trust (block #2).
  • The answer is delivered to a deterministic state machine that couldn't fetch it itself (block #3).
